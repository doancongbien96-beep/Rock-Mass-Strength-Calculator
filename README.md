# Rock Mass Strength Calculator

Standalone Generalized Hoek–Brown calculator recovered from the original ChatGPT project.

Live site: https://doancongbien96-beep.github.io/Rock-Mass-Strength-Calculator/

Open index.html locally to run the calculator. No build or dependency installation is required. Includes reference pickers, principal/shear stress plots, report and Excel export.

GitHub Pages publishes the root of the main branch. The .nojekyll file enables direct static hosting.
